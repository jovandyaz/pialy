# Pialy

Apuesta por tu cita: el cliente aparta su lugar pagando un depósito de $0.01 MXN vía CoDi, usando la API de pey.

## Cómo correrlo

```sh
nvm use            # Node 24
pnpm install
cp .env.example .env   # completa los valores
pnpm -r typecheck
pnpm -r test
pnpm lint
```
